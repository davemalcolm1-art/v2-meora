# Welcome to Meora
# MEORA

**Australian telehealth and peptide therapy platform**

MEORA is a clinically-led, AHPRA-compliant telehealth service connecting Australians with registered doctors for evidence-based peptide therapy programs. Built on a longevity medicine framework — GH axis support, recovery, metabolic health, and healthy ageing.

---

## Stack

- **Framework:** React + TypeScript + Vite
- **Styling:** Tailwind CSS + shadcn/ui
- **ORM:** Drizzle
- **Package manager:** Bun
- **Dev platform:** Lovable
- **Deployment:** Vercel (planned)

---

- **Heading font:** Cormorant Garamond

## Getting Started

```bash
# Install dependencies
bun install

# Run development server
bun dev

# Build for production
bun run build
```

---

## Compliance

MEORA operates within the Australian regulatory framework:

- All programs require consultation with an **AHPRA-registered doctor**
- Prescriptions dispensed by a **TGA-licensed compounding pharmacy**
- Marketing compliant with **AHPRA advertising guidelines**
- Content strategy separates health service promotion from therapeutic good advertising
